# Full Cycle Rocks

Aplicação em Go que imprime `Full Cycle Rocks!!`. A imagem publicada tem menos de 2MB.

## Imagem no Docker Hub

https://hub.docker.com/r/reialexandre/fullcycle

## Como baixar e rodar a imagem

```bash
docker run reialexandre/fullcycle
```

Saída esperada:

```text
Full Cycle Rocks!!
```
